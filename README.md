# IG Video Downloader (FastAPI + iOS Shortcuts)

API sederhana menggunakan Python untuk mengunduh video Instagram dan diintegrasikan dengan iOS Shortcuts.

My first scraping project in Python.

## Tech Stack

- **Python 3**
- **FastAPI**
- **yt-dlp**
- **iOS Shortcuts**
